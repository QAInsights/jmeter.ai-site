01

AI Test Generation

Describe the test element you need in plain English. Feather Wand generates JMeter scripts, assertions, and extractors with full context of your existing test plan.

# Generate an HTTP sampler with auth and JSON body
jmeter-ai feather-wand --generate "POST /api/v1/login with bearer token"
02

Command Palette Navigation

Super Key brings VS Code-style keyboard shortcuts to JMeter. Open the command palette, fuzzy-search any element, and jump to it in under two keystrokes.

03

Multi-Tab Test Plans

Prism replaces the single-document model with Chrome-style tabs. Work across multiple JMX files simultaneously without restarting JMeter.

04

Performance Calculators

Perftractor embeds Little's Law, concurrency, and throughput calculators directly into the IDE. No context switching to spreadsheets.

05

Theme Engine & Documentation

JMeter Studio provides dark, light, and high-contrast themes. README Config keeps test plan documentation version-controlled and readable inside the tree.
