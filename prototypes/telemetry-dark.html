Capabilities

What you get

  • AI Test Generation — Describe elements in English. Feather Wand generates scripts, assertions, and extractors.
  • Command Palette — Super Key brings VS Code-style navigation. Find any element in two keystrokes.
  • Multi-Tab Editor — Prism replaces single-document mode. Work across multiple JMX files.
  • Performance Calculators — Little's Law, concurrency, throughput. No spreadsheet switching.
  • Theme Engine — Dark, light, high-contrast. Custom CSS for corporate branding.
